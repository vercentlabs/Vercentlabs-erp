# Manufacturing → Accounting Cost/Reconciliation Contract

Manufacturing calculates deterministic planned/actual material, labor, machine, overhead, subcontract and scrap cost facts; Stock owns inventory valuation; Accounting owns journal/period/GL. Idempotent posting contracts map WIP, finished output and variances with source-effect uniqueness, period-lock checks, reversals and a reconciliation view from work order → Stock layers/movements → journal lines.
