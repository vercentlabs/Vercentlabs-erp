## Net assessment (2026-09-06, gap-closed)

Both halves of partial fulfilment are now real: the bookkeeping (accumulation across multiple requests, correct ceilings, billing-basis flexibility) was already solid, and completing a fulfilment now genuinely issues stock via Stock's own movement/valuation system, matching F046's reservation-side fix as the other half of real Sales-to-Stock integration. A pre-existing, fully-broken code path (`positiveAmount` undefined) was also found and fixed in the process. One smaller gap remains, not addressed this pass: no delivery tolerance or remainder-cancellation action.
