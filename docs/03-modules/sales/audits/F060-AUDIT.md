## Net assessment (2026-09-06)

The underlying report queries are real and (after this session's fix) correctly scoped, but the analytics *capability* around them is thin — no filters, no drilldown API, no export, no configurable date range, no report-level snapshotting. This is a much less developed reporting surface than CRM's equivalent (F021/F024), which had real export/security-hardening work already done. Recorded for the gap-closing pass as a genuine feature-breadth gap, not a defect in what already exists.
