# F034 Price lists — Atomic requirement trace

Verified against `SUBREQUIREMENT_REGISTER.csv` (37 rows) by reading `calculateLine`'s price-list resolution (`services/api/src/modules/sales/index.js:322-370`), `upsertSalesPriceListItem`/`upsertSalesCustomerPrice` in full (`services/api/src/modules/sales/pass1-operations.js:163-267`, the "Pass 1" admin surface for Sales-specific pricing content), and `tenant.price_lists`' ownership in `services/api/src/core/master-data.js:1504` (the shared header table Sales only ever reads).

Like customers, Sales does not own the `price_lists` header table — that's shared master data (`core/master-data.js`). Sales owns and mutates only its own pricing *content*: `tenant.price_list_items` (rates per item/UOM/quantity break) and `tenant.sales_pricing_rules` (discount/fixed-rate overrides scoped by company/party/item/item-group/price-list).
