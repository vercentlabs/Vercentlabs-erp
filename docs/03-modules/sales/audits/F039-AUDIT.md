## Net assessment (2026-09-06)

The one gap found — no header/document-level discount — is fixed. It integrates with the existing approval-threshold and permission-override machinery rather than sitting beside it as a separate, ungoverned lever. Note: `sales_order_versions` doesn't persist `maximum_discount_percent` at all (a pre-existing asymmetry with quotations, not introduced by this fix, and out of scope for it) — orders get the same correct total-calculation behavior but not the same order-side approval-threshold tracking quotations get.
