## Net assessment (2026-09-06)

The reconciliation engine itself is one of the strongest pieces of code found in the whole Sales trace — genuinely cross-domain, policy-driven, not hardcoded. The one real gap is narrow but concrete: the computed `readyToClose` signal has no corresponding action anywhere to actually close the order, so orders never reach their terminal `closed` state no matter how complete they are. A small, well-scoped fix for the gap-closing pass (a `closeSalesOrder` function gated on the same `readyToClose` condition).
