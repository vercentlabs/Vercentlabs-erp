# Procurement Permission Matrix

Audited permission families include procurement view/settings; supplier view/manage/qualify/sensitive; catalog; requisition create/manage/approve; sourcing manage/evaluate/award; contract manage/approve; PO create/manage/approve/dispatch/amend/cancel; receipt manage/approve; inspection; returns; matching manage/override; supplier portal; reports and audit. Every action is server-rechecked. Supplier banking/tax data, confidential bids/evaluations, match overrides and approval evidence require stricter field/action scope and negative tests.
