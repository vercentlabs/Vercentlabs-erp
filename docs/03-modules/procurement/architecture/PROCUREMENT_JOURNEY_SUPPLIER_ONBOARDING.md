# Procurement Journey — Supplier Onboarding to Spend Authorization

A prospective/internal registration creates a supplier candidate; duplicate/legal/tax/site/contact checks, required qualification/certification evidence and sensitive banking verification are completed under least privilege. Approval converts the same supplier lineage to spend-authorized state exactly once. Rejection/suspension preserves reason/history. No unapproved supplier can be used for purchasing commitments unless an explicit governed emergency policy permits it.
