# HR & Payroll Module Blueprint

- Pass: 11
- Canonical range: F381–F452
- Feature count: 72
- Product boundary: Workforce identity/lifecycle, recruiting, time/leave, compensation, deterministic payroll, India statutory compliance, performance and learning
- Specification status: `SPECIFICATION_READY`

HR & Payroll is an effective-dated workforce and deterministic payroll control plane. Payroll consumes frozen source versions, preserves maker-checker approval, emits idempotent payment/accounting/statutory effects and reconciles them. Sensitive employee/payroll data uses least privilege and field masking. Statutory rules are jurisdiction/tax-year/effective-date configuration supported by authoritative sources, not timeless constants.

Pass 11 certifies specification readiness only; implementation/product readiness remains separate.
