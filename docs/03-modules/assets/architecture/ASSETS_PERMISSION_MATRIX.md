# Assets Permission and Segregation Matrix

| Role | Register/custody | Maintenance/inspection | Financial value/depreciation | Disposal | Audit/report |
|---|---|---|---|---|---|
| Asset manager | Manage | Manage/coordinate | View limited/configured | Request/manage | View |
| Asset accountant/controller | View | View | Manage/approve/post intent | Approve/financialize | Full financial |
| Maintenance manager | View | Manage | No sensitive edit | No | Maintenance reports |
| Technician/inspector | Assigned scope | Execute evidence | No | No | Own/assigned evidence |
| Custodian | Own assigned assets | Request service | No | No | Own assignment |
| Auditor | Read | Read | Read | Read | Read/export |

Sensitive maker-checker actions include capitalization, depreciation approval/posting intent, revaluation/impairment, disposal approval/completion and configured compliance closure. Record scope must not leak cost/NBV/custodian or maintenance evidence through aggregates/search.
