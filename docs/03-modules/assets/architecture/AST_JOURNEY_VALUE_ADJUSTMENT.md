# Journey — Revaluation / impairment to books

1. Select eligible asset/book and effective date; lock current carrying-value snapshot.
2. Capture approved valuation/impairment evidence and reason.
3. Enforce permission/SoD and Accounting period/effectivity policy.
4. Calculate deterministic adjustment without rewriting prior depreciation history.
5. Submit idempotent Accounting intent with source snapshot/correlation ID.
6. Persist reconciliation state; downstream rejection remains explicit/retryable.
7. Future depreciation schedule changes are versioned from the approved effective date.
