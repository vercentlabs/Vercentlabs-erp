# Projects Permission Matrix

| Persona | Typical rights | Restricted by default |
|---|---|---|
| Project Manager | project/WBS/task/progress, team, issues/risks | finance approval, cross-project confidential data |
| Team Member | assigned tasks, own time/expense, permitted comments/docs | other users rates, budget/margin, approvals |
| Resource Manager / PMO | allocation/availability, portfolio schedule | restricted customer finance unless granted |
| Project Controller | budget/cost/revenue/billing/profitability | delivery edits outside role |
| Billing / Finance | billing approval/handoff, reconciliation | project scheduling unless granted |
| Executive | aggregated dashboards/reports | underlying restricted records unless separately authorized |

Every route also enforces tenant, company, project/team/record scope server-side.
