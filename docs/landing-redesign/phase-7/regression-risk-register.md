# Phase 7 Regression Risk Register

Every serious bug found across Phases 2-7, mapped to what now prevents it from recurring silently. "Silently" is the operative word for most of these — none of them produced a build error or a lint error; every one was caught only by actually running the app and looking (visually, via a real browser test, or via a real HTTP/console check). This register exists so a future maintainer re-encountering a similar-looking failure can immediately tell whether it's one of these categories recurring or something genuinely new.

## Known gaps (not fixed this phase, documented rather than silently left implicit)

- **Two analytics events bypass the type-sync guard** (`sticky_mobile_cta_click`, `implementation_specialist_cta_click`) — see item 6 above and `analytics-event-contract.md`'s closing note.
- **`playwright.config.ts`'s `reuseExistingServer` pattern doesn't verify the reused server is actually a production build** — a real methodology risk this phase encountered directly (`decision-log.md` item 8) and worked around per-run, but the config itself still has the underlying gap. Flagged for `phase-8-brief.md`.
