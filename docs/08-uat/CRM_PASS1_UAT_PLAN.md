# CRM Pass 1 UAT Plan

For each F001–F030, execute two human scenarios: (1) front-line primary job including a high-frequency responsive path; (2) manager/operations permission/exception/reconciliation path. Capture actor/role, prerequisites, exact steps, visible result, resulting state/history/audit, downstream effects and evidence reference. Specification-ready means the UAT cases are designed; product-ready later requires execution evidence.
