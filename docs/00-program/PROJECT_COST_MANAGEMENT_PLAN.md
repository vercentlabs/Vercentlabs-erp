# Project Cost Management Plan

Status: `PM_BASELINE_FROZEN`
Accountable owner: `Project Manager`

The repository does not contain sufficient provider/pricing evidence to invent an implementation cost forecast. Therefore this baseline is a **spend-control baseline**, not a fabricated budget forecast.

Rules:
- no paid external service is implicitly authorized;
- the current authorized paid amount for unselected external services is zero;
- before any paid provider/service commitment, the Project Manager records provider, pricing basis, amount/cap, affected requirements/risks and the approval decision through change control;
- existing sunk costs or owner time are not assigned an invented monetary value;
- production operating costs remain separate from implementation authorization until providers and usage assumptions are selected.

`docs/02-register/PROJECT_COST_BASELINE.csv` is the control register.
