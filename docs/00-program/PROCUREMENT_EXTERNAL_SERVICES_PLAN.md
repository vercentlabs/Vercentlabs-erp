# Procurement and External Services Plan

Status: `PM_BASELINE_FROZEN`
Accountable owner: `Project Manager`

No external person or vendor is assigned project responsibility by this plan.

Current rule: **no unselected paid external service is pre-authorized**.

Before committing to hosting, database, observability, storage, paid AI/API/SaaS, payment-production services or other external services, the Project Manager must document:
1. requirement/use case;
2. provider/options considered;
3. security/data-residency/compliance implications where relevant;
4. pricing basis and spending cap;
5. lock-in/exit implications;
6. affected architecture, cost and RAID records;
7. explicit approval decision.

Provider selection is deferred until the relevant technical or operational gate requires it. Deferral is not permission for an implementation agent to select a paid service silently.
