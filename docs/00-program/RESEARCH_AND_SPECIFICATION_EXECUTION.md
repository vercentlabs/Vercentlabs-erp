# Research and Specification Execution

The 12 module passes remain the execution unit: CRM; Sales; Procurement; Stock; Manufacturing; Projects; Assets; POS; Quality; Support; HR & Payroll; Accounting.

Every pass follows: domain research -> official vendor research -> current-code inventory -> feature decomposition -> capability mapping -> user-flow modelling -> data/state/domain design -> UX/responsive/accessibility specification -> security/integration design -> tests/E2E/UAT -> independent red-team review -> machine validation -> readiness promotion.

Do not generate all feature content in one undifferentiated AI pass. The framework may be installed in one command, but actual subfeatures must be evidence-backed and reviewed module by module.
