# Master Traceability Model

The implementation trace is:

`F-ID -> capability/sub-capability -> atomic requirement -> flow/state machine -> data/invariant -> command/query/event -> API -> web/mobile surface -> permission/scope -> test -> enterprise journey -> UAT -> implementation evidence`.

`docs/02-register/FEATURE_BUILD_MANIFEST.csv` summarizes each F-ID's current planning links. `docs/02-register/TRACEABILITY_GRAPH.csv` provides requirement-level machine-readable edges. Missing links are planning debt, not permission for an AI agent to invent behavior.
