# Communications Plan

Status: `PM_BASELINE_FROZEN`
Accountable owner: `Project Manager`

Because the project currently has one accountable person, communication control is repository-first and event-driven rather than meeting-driven.

Update the authoritative repository record when any of these events occurs:
- a gate decision changes;
- a material requirement or architecture decision changes;
- a RAID item is opened, materially changed or closed;
- an external cost/procurement commitment is considered or approved;
- implementation evidence changes the current checkpoint;
- a wave exits or a successor wave is opened.

No recurring meeting, reporting date or calendar cadence is imposed by this plan. The repository checkpoint, RAID register, decision records and validators are the communication system of record.
