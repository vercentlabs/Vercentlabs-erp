# Stakeholder Management Plan

Status: `PM_BASELINE_FROZEN`
Accountable owner: `Project Manager`

Only the Project Manager is assigned a current project role.

Future pilot users, customers, service providers and authorities are stakeholder groups, not project assignees. They are engaged only when the relevant acceptance, procurement or compliance gate is explicitly opened.

Until direct engagement occurs, product-user interests are represented through the frozen feature requirements, enterprise journeys, accessibility/security standards and UAT obligations already present in the repository.

Every stakeholder decision or material external constraint is recorded in repository evidence before it can change scope, architecture, acceptance criteria, cost authorization or implementation sequence.
