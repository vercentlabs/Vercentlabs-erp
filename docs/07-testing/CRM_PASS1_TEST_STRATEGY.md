# CRM Pass 1 Test Strategy

Every F001–F030 maps to approved UNIT/domain, API/contract, permission-negative, RLS/data-scope where applicable, integration/idempotency, E2E/browser and UAT requirements. F001–F014 already have conspicuous named tests in the audited snapshot; F015–F030 require equally explicit requirement-to-test mapping rather than assuming generic coverage.

Release implementation certification later must also prove representative-volume performance, accessibility human/keyboard checks, migration/reconciliation, provider/webhook replay safety and cross-module F023→F036 handoff behavior.
