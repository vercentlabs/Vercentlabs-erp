# Visual Specification Standard

Major operator workspaces require visual evidence, not text-only UX prose. At minimum capture desktop, tablet and mobile behavior where applicable.

Each visual specification must answer: primary action; above-the-fold information; list/detail/board/calendar/Gantt/ledger/work-queue choice; loading/empty/error/conflict/permission states; localization/long-content behavior; keyboard path; non-drag alternative; mobile reflow; destructive-action confirmation; and the relation to actual domain state.

Store durable assets in `docs/11-visual-assets/` and reference them from the governing dossier/capability contract.
