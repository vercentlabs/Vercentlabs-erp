# Stock Pass 4 Workspaces

## Desktop
Inventory dashboard → availability grid → item/warehouse/lot/serial 360; ledger and valuation drilldown; count/replenishment/exception queues; pick-pack-ship workbench.

## Tablet / handheld
Large scan target → location/item/lot/serial confirmation → quantity → exception → confirm. Critical warehouse actions never require drag-and-drop.

## Phone
Card/step-flow alternatives for receipt, transfer, count, pick, pack, ship, return and trace lookup; sticky primary action and explicit offline/retry state.
