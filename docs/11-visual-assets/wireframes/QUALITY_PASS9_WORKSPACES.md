## CAPA

## Traceability / CoA
Lot genealogy graph + inspections/holds/dispositions/customer/supplier links → select approved evidence → CoA preview/approval/issue/reissue history.

## Dashboard
Exception-first cards for failed/overdue inspections, active/aging holds, NCR/CAPA due, calibration expiry, supplier/complaint trends and cost-of-quality with permission-safe drilldown.
