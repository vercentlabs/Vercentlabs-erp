# Manufacturing Pass 5 Low-Fidelity Workspace Specification

## Desktop
Manufacturing shell: KPI/exception strip → saved-view planning/order grid → optional Gantt/capacity board → inspector/detail pane. Engineering compare shows old/new BOM/routing effectivity and impact. Work-order 360 combines structure snapshot, materials, operations/times, quality, genealogy, cost and history.

## Tablet / shop floor
Large job-card header, start/pause/complete controls, current operation/instructions, material scan/consume/return, lot/serial capture, quality step, scrap/rework/downtime reason, timer and next work. Critical actions stay available without desktop-only tables.

## Phone
Assigned-work cards and guided step flow. Scanner has manual accessible alternative. Offline boundaries are explicit; queued mutations display pending/retry/conflict state rather than implying completion.
