# Projects Pass 6 Low-Fidelity Workspace Specification

## Desktop
Project shell: header/status/actions -> KPI/exception strip -> tabs for Overview, Plan/WBS, Gantt, Board, Calendar, Team/Capacity, Time/Expense, Materials/Procurement, Budget/Financials, Billing, Risks/Issues, Documents/Activity and Audit. Dense views use inspector/detail panes and stable URL state.

## Tablet
Split-pane task/WBS and project detail, touch-friendly board/calendar, weekly time/expense capture and approvals.

## Phone
Assigned-work cards, task update, timer/time entry, expense capture, approvals, risk/issue/comment updates and project summary. Financial details collapse into accessible cards. Drag operations always have button/menu alternatives.
