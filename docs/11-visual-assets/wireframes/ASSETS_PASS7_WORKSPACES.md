# Assets Pass 7 Low-Fidelity Workspaces

## Desktop asset 360
`Header/tag/status/actions | identity/category/source | location/custody | financial book/value | maintenance/warranty | inspections/calibration | verification | disposal | immutable timeline`

## Maintenance planner
`Due/overdue queue | calendar/board | asset availability | technician/parts | work-order detail | downtime/reconciliation`

## Depreciation controller
`Book/company/period filters | run summary | exceptions | schedule drilldown | approval | Accounting result/reconciliation | reversal`

## Mobile scanner / verification
`Scan QR/barcode → asset summary → verify location/custodian/condition → photo/evidence → discrepancy or permitted action → queued/offline indicator → sync/conflict result`

## Disposal controller
`Eligibility/open obligations | current carrying value | sale/scrap inputs | approval evidence | calculated gain/loss preview | Accounting handoff/result | reversal history`

All views include empty/loading/error/stale/conflict/permission/offline states and WCAG 2.2 AA interaction alternatives.
