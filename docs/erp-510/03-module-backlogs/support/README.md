# Support — Mandatory Feature Backlog

This directory tracks mandatory Support capabilities.

Features assigned to this module must reference their canonical specification
under:

../../02-feature-specs/

## Status Rules

Allowed implementation statuses:

- NOT_STARTED
- AUDITING
- REQUIREMENTS_READY
- IMPLEMENTING
- TESTING
- UAT
- COMPLETE
- BLOCKED

Allowed UAT statuses:

- NOT_READY
- LIMITED
- READY
- BLOCKED

No feature may be marked COMPLETE without satisfying the global Definition of Done.
